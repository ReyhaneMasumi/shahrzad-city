# Todo API Reference

All endpoints are mocked via MSW (Mock Service Worker). No real server required.

**Base URL:** `/api` (relative, runs in-browser via service worker)

**Behavior:**

- 300–700ms simulated latency on writes (POST/PATCH/DELETE)
- ~20% random failure rate on writes — your UI must handle errors gracefully
- Reads (GET) have only 200ms delay and no failures

---
