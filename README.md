
## Agent standards

This kit also incorporates:

- The official Next.js AI coding agent guidance and version-matched bundled docs.
- Official Next.js workflow skills for runtime verification, Cache Components, instant navigation, and Partial Prefetching.
- Airbnb React/JSX conventions as a secondary code-style reference.

The project intentionally does not copy Next.js framework-internal contributor skills that are irrelevant to application development.
